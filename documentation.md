# Documentation

## agent.py

### Overview
The `agent.py` file contains the implementation of the reinforcement learning agent, which interacts with the environment to learn and optimize its performance based on rewards. The agent utilizes various algorithms for training and evaluation.

### Key Classes and Methods

- **Agent Class**
  - **learn()**: 
    - Main method for training the agent. It performs rollouts, computes advantages, and updates the actor and critic networks.
    - Handles multiple epochs of training over the same set of data.
  
  - **value_step()**: 
    - Computes the values based on the agent's actions and the environment's rewards.
    - Calculates harm and help values using the critic networks.

  - **rollout()**: 
    - Interacts with the environment to collect data (state, actions, rewards) for training.
    - Handles the generation of actions and the collection of rewards.

## models.py

### Overview
The `models.py` file defines the architecture of the neural networks used by the agent, including the transformer-based models for both the actor and critic.

### Key Classes and Methods

- **TransformerPolicy Class**
  - **overview**:
    - The TransformerPolicy class is a neural network architecture designed for policy learning in reinforcement learning environments. It is instantiated with a huggingface model and tokenizer, and fine-tunes the final layer and input embeddings.
  - **load_state_dict()**: 
    - Loads only the trainable parameters (final layer and input embeddings) from a given state dictionary.
  
  - **state_dict()**: 
    - Saves only the trainable parameters of the model.
  - **forward()**:
    - Defines the forward pass of the transformer policy, processing input IDs or embeddings and returning the output.
  - **generate()**:
    - Generates a response from the model based on the input prompt.
  - **get_log_probs()**:
    - Computes the log probabilities of the actions taken by the model.
  - **sample_top_k()**:
    - Samples the top k actions from the model's output logits.
    

- **ValueTransformerPolicy Class**
  - **overview**:
    - The ValueTransformerPolicy class is a neural network architecture designed for value estimation in reinforcement learning environments. It is instantiated with a huggingface model and tokenizer, and implements a transformer encoder-decoder architecture for the trainable final layer. The output is a single value per input sequence.
  - **forward()**: 
    - Defines the forward pass of the value transformer policy, processing input IDs or embeddings and returning the output.

## env.py

### Overview
The `env.py` file implements the environment in which the agent operates. It defines how the agent interacts with the environment, including the evaluation of actions and the generation of rewards.

### Key Classes and Methods

- **SingleStepEnv Class**
  - **overview**:
  This method is deprecated and should not be used. The SingleStepEnv class is not used in our experiments because it is not integrated with a target LLM. It only uses data as an input or ChatGPT's API, both of which are unsuitable for learning.

- **MultiStepEnv Class**
  - **__init__()**: 
    - Initializes the multi-step environment for reinforcement learning, loading models and setting up the environment.
  - **step()**:
    - Performs a single step in the environment, interacting with the target LLM and calculating rewards. Returns the state, reward, and next state. The state is stored as a list of list of strings, where the inner lists contain the alternating user and assistant messages.
  -**get_target_response()**:
    - Queries the target LLM for a response to the given question.
  - **score_helpfulness()**:
    - Scores the helpfulness of the last message in the chat history with respect to previous messages. Helpfulness is defined as the ratio of the logits of the "YES" and "NO" tokens in the last message, which are generated by the target LLM when queried to rate if the response is helpful.
  - **score_safety()**:
    - Returns a tensor of scores between 0 and 1 for each question in the batch, indicating the safety of the response according to the guard model. The safety score is defined as the probability of the "SAFE" token in the last message, which is generated by the guard model. The guard model is a small LLM that is trained to detect harmful content, provided by Meta.
    

## helpers.py

### Overview
The `helpers.py` file contains utility functions that assist in various tasks, such as generating responses from the language model, creating message formats, and logging data.

### Key Functions

- **LLM_get_response()**: 
  - Queries the OpenAI GPT-3 model for a specific prompt and returns the response.

- **create_messages()**: 
  - Constructs a message format for the chat model based on user input and system instructions.

- **log_generations()**: 
  - Logs the input and output tokens generated by the model, saving the data to a CSV file for analysis.

- **plot_rephrase_scores()**: 
  - Visualizes the scores of original and rephrased questions using histograms.

- **check_device_mem()**: 
  - Checks if the allocated memory exceeds a specified threshold of the maximum GPU memory.

- **triangle_attn()**:
  - Returns a lower triangular matrix of ones with the shape of the input.
- **build_chat()**:
  - Builds a chat history from a list of messages.
  - The chat history is a list of dictionaries, where each dictionary contains the role and content of a message.
  - The position of the user messages are noted by the user_num parameter, where message_index % user_num == 0 indicates a user message within the chat history.
### Additional Notes
- The files are designed to work together in a reinforcement learning framework, where the agent interacts with the environment, learns from feedback, and utilizes transformer models for decision-making and evaluation.
